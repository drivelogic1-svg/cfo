# cfo

## Правовая справка: запреты на ввоз товаров в Республике Казахстан (2026)

Готовый документ: **`Запреты_на_ввоз_товаров_РК_2026.pdf`** (14 страниц, A4, на русском языке).

Справка проверяет сведения о постановлении 2026 года, запрещающем ввоз товаров в Казахстан,
и фиксирует фактически действующие ограничения по состоянию на 22.10.2026:

| Товар | Акт | Статус |
|---|---|---|
| Пшеница (1001) | Приказ МСХ РК № 273 от 11.07.2026 | действует |
| Яблоки (0808 10) | Приказ и.о. МСХ РК № 326 от 01.09.2026 | действует |
| Чай (отдельные наименования) | Постановление ГГСВ РК от 05.01.2026 | действует |
| Вейпы и жидкости | Закон РК № 74-VIII от 19.04.2024 | действует (постоянно) |
| Яйца кур свежих (0407 21) | Приказ МСХ РК № 146 от 17.04.2026 | истёк 21.10.2026 |
| Томаты (0702) | Приказ МСХ РК № 250 от 22.06.2026 | истёк 30.06.2026 |
| Строительные материалы | Приказ МПС РК № 237 от 15.05.2026 | отменён 17.10.2026 |

Основной вывод: единого постановления Правительства РК о запрете ввоза товаров в 2026 году
не принималось — ограничения вводились приказами профильных министров.

### Сборка PDF в GitHub Actions

PDF собирается автоматически workflow **`.github/workflows/build-pdf.yml`**.

| Событие | Что происходит |
|---|---|
| push в `main` или `arena/**` (файлы `reports/**`, `requirements.txt`, workflow) | сборка + артефакт |
| pull request с теми же изменениями | сборка + проверка PDF, без публикации |
| ручной запуск (`workflow_dispatch`) | сборка; опционально — приложить PDF к последнему релизу |
| публикация релиза или тег `v*` | сборка + PDF прикрепляется к релизу |

**Где забрать результат:** вкладка *Actions* → запуск **Build PDF** → блок
*Artifacts* → **zaprety-na-vvoz-2026-pdf**. Артефакт хранится 90 дней.

Workflow ставит `fonts-dejavu-core`, собирает PDF скриптом и проверяет результат:
число страниц, наличие текста (защита от «пустых» страниц при отсутствии шрифтов)
и закладки. Итоговые метрики попадают в Summary запуска.

### Локальная сборка

```bash
sudo apt-get install -y fonts-dejavu-core    # шрифты с кириллицей
python3 -m pip install --break-system-packages -r requirements.txt
python3 reports/build_import_bans_report.py
```

Переменные окружения: `FONT_DIR` — каталог со шрифтами DejaVu, `PDF_OUT` — путь
к итоговому файлу. Скрипт `reports/build_import_bans_report.py` содержит весь текст,
вёрстку и генерацию закладок PDF; шрифты — DejaVu (кириллица, казахские диакритические
знаки).
